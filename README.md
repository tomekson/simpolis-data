# simpolis-data

Veřejný katalog školních akcí VŠEM pro Šimpoliš a Rozcestník.

- **`katalog.json`** zapisuje Google Apps Script z dat, která posílají instance Šimpoliše. Ručně se needituje.
- **Obsahuje jen veřejné údaje o akcích:** názvy, popisy, termíny, okna přihlašování a kapacitu. Žádné osobní údaje, stav přihlášení ani identitu odesílatele.
- **Hlavní kopie je na Google Disku.** Tenhle repozitář je zrcadlo pro GitHub Pages: https://tomekson.github.io/simpolis-data/katalog.json
